## 已实现

- `langgraph_app/context.py` 构造模型输入视图：BOM保留所有候选的完整details（含父链、路径、类型及现有方法元数据），省去重复展示文本；规则保留程序已填参的全部四段文本，省去重复details。错误保留失败标记与友好文案。不删候选、不用摘要替换阈值或动作。
- 同轮完全相同的成功结果用tool_call_id引用，原始结果仍在检查点及工具事件中；跨用户轮次重新登记，防止摘要丢掉引用目标。模型输入移除reasoning_content；浏览器处理过程与原检查点保留。
- 对模型、摘要、交付修正的完整请求统一检查提示、工具Schema、输出预留及2048模板余量。UTF-8字节作为byte tokenizer的保守上界，日志标为inputTokenUpperBound，不能当真实token用量。过长明确失败，不截断原文或执行半截工具调用；该上界可能保守拒绝实际能够容纳的请求，真实服务容量仍需一致配置。
- 转换连续两批工具请求全部命中已有缓存时进入收尾，或8批检索后收尾；收尾禁用工具并要求完整草稿及待确认项。不声称所有字段已映射；若模型仍返回工具调用则拒绝执行。普通问答和已有规则宿主全文展示保持原路径。
- 每项任务最多16次模型generate调用，统一计入摘要及交付修正；适配器HTTP瞬时故障重试最多3次/调用，不能将16误称为最多16次HTTP请求。普通12轮和48次工具预算保留。
- 默认任务总期限600秒，`AGENT_TASK_TIMEOUT_SECONDS`和`AGENT_MODEL_REQUEST_LIMIT`可设正整数。超时取消生成并关闭工具进程，发错误与agent_settled；已接收过程保留，不把半成品当定稿。
- 标准stream_options.include_usage请求服务返回实际用量，可通过适配器config的stream_usage=false关闭；无返回仍为null。增加首个正文/思考增量耗时、HTTP尝试次数和输入规模诊断，不记录业务正文或凭据。firstOutputMs不含纯工具调用首输出，不能混称全部输出类型的TTFT。
