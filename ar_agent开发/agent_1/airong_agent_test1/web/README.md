# 前端

此目录只保存浏览器端静态资源：

- `index.html`：页面结构。
- `app.js`：Vue 交互、会话存储、附件上传和 SSE 事件处理。
- `styles.css`：页面样式。
- `vendor/`：本地 Vue 库。

页面由 `backend/main.py` 托管，无前端构建步骤。请在项目根目录运行 `run-web.ps1` 后访问网页；直接双击 HTML 无法使用后端 API。

Python 运行层、虚拟环境、依赖、测试和启动脚本已移出此目录。完整结构和启动方式见 [项目 README](../README.md)。

一次用户提问对应一个助手气泡。工具调用前的中间文字与思考归入默认折叠的“处理过程”，展开后在限定高度内滚动查看，最终答复显示在正文。旧localStorage消息保持原样。验证入口为项目根目录的 `node tests/web_status.cjs`，该检查使用Vue stub，不替代浏览器验收。

编辑器整合（2026-10-30）：顶栏可在规则助手与 8009 文档编辑器间切换；编辑器首次打开时加载，此后切换保留其页面和聊天状态。助手定稿消息可复制完整答复后切换，用户在编辑器粘贴所需规则并使用原验证功能；复制失败有提示。若内嵌页无法使用，可用“独立窗口打开”。编辑器沿用自身登录，不传递凭据、不自动提交或保存规则。地址当前为 app.js 中的 http://127.0.0.1:8009/，面向本机使用。Logo 为 assets/company-logo.svg，配色与编辑器一致。新增验证：node tests/web_editor.cjs。
