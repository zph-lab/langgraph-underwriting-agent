使用说明

        
规则是一段自由文本，语义单元之间用空格分隔，例如：

        

          如果 保单的个团标志 是 动态域集的个团标志的团单
        

        

          1. 空框点击或按回车，弹出入口候选 预定义 / 如果 / 那么 / 否则。

          2. 输入（或回车选中）引导词后按空格进入对应模式：如果 → 规则模式；预定义 → 预定义模式（其后选 指定 定义别名，如 `预定义 指定'A费用上限'为'保单'的…`）；那么/否则 → 动作模式。

          3. 规则模式：输入文字后按光标所在的词检索候选；空格进入新词，弹出运算符/连接词候选。

          4. 选中候选填入后仍是普通文本，可随时修改；两个空格之间的文本参与一次检索。
