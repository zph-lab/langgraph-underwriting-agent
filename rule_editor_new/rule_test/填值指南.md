# 规则 HHZ2026941103 填值指南

> 适用骨架（`getInputByRuleId` 返回）：
> ```json
> {"appbase": {"csubdpt": null, "cthirddpt": null, "productLifeInfo06": {"coverage062008List": null}},
>  "dynamicsAttributeList": {"Csubdpt": {"Cdptcde_0265010000000": null}}}
> ```

## 一、规则命中条件速览

```
保单的二级机构 是 动态域集的归属机构的新疆
并且 保单的三级机构 是 0265220000000
并且 ( 险别代码是060051的记录满足 [金额≤3000000 且 费率≥2 且 打折≥75]
   或 险别代码是060835的记录满足 [金额≤3000000 且 费率≥2 且 打折≥100] )
```

**两种命中组合**（同一条险别记录上四个字段必须同时成立，严禁跨记录拼凑）：

| 组合 | ccvrgno | namt | nrate | nfloatrate |
|---|---|---|---|---|
| A | `060051` | ≤ 3000000 | ≥ 2 | ≥ 75（含边界） |
| B | `060835` | ≤ 3000000 | ≥ 2 | ≥ 100（含边界） |

## 二、预定义变量的挂载点映射（核心）

预定义行：

```
指定'当前险别'为一个 062008借款人意外伤害保险B款 来自(in) '保单'的人身险信息的062008借款人意外伤害保险B款险别列表
```

含义：条件树里所有 `规则预定义变量.当前险别.*` 字段，实际取值位置是**保单报文中"人身险信息"下的 062008 险别列表**，即骨架中的：

```
appbase.productLifeInfo06.coverage062008List   ← 列表类型，逐条险别记录
```

因此 `coverage062008List` 要填成**险别记录数组**，每条记录含四个字段：

| 字段 | 含义 | 填值说明 |
|---|---|---|
| `ccvrgno` | 险别代码 | 字符串：`060051` 或 `060835`（决定走哪个组合） |
| `namt` | 保险金额 | 数值，≤ 3000000 |
| `nrate` | 基准费率(‰) | 数值，≥ 2 |
| `nfloatrate` | 打折系数(%) | 数值：组合 A ≥ 75；组合 B ≥ 100 |

> 本地求值器对两种填法都能识别：①骨架同款 BOM 列表路径（推荐，与接口一致）；②ruleContent 原路径 `规则预定义变量.当前险别`（dict）。**给 ADP 提测时一律用 ①。**

## 三、骨架 → 填值对照表

| 规则条件 | 骨架路径 | 填值 |
|---|---|---|
| 保单的二级机构 是 动态域集的归属机构的新疆 | `appbase.csubdpt` | `"0265010000000"` |
| 域集成员（与上一条联动） | `dynamicsAttributeList.Csubdpt.Cdptcde_0265010000000` | `"0265010000000"`（键值与 csubdpt 相同） |
| 保单的三级机构 是 0265220000000 | `appbase.cthirddpt` | `"0265220000000"` |
| 当前险别四字段 | `appbase.productLifeInfo06.coverage062008List[...]` | 见上表 |

## 四、可直接使用的命中报文

**组合 A（060051，含边界值）**：

```json
{
  "appbase": {
    "csubdpt": "0265010000000",
    "cthirddpt": "0265220000000",
    "productLifeInfo06": {
      "coverage062008List": [
        {"ccvrgno": "060051", "namt": 3000000, "nrate": 2, "nfloatrate": 75}
      ]
    }
  },
  "dynamicsAttributeList": {"Csubdpt": {"Cdptcde_0265010000000": "0265010000000"}}
}
```

**组合 B（060835）**：同上，仅换列表元素为

```json
{"ccvrgno": "060835", "namt": 3000000, "nrate": 2, "nfloatrate": 100}
```

**多险别**：列表可放多条记录，**任意一条**满足完整组合即命中：

```json
"coverage062008List": [
  {"ccvrgno": "060052", "namt": 3000000, "nrate": 2, "nfloatrate": 100},
  {"ccvrgno": "060051", "namt": 3000000, "nrate": 2, "nfloatrate": 75}
]
```

## 五、典型不命中场景

| 场景 | 结果 | 原因 |
|---|---|---|
| `nfloatrate=74`（060051） | 不命中 | 未达组合 A 下限 75 |
| `nfloatrate=99.99`（060835） | 不命中 | 未达组合 B 下限 100 |
| `namt=3000001` / `nrate=1.99` | 不命中 | 超上界 / 低于下界 |
| `ccvrgno=060052` | 不命中 | 不在两个组合的险别代码内 |
| 险别记录 A：060051+74；记录 B：060052+100 | 不命中 | **跨元素拼条件无效**，四个字段必须在同一条记录上 |
| `csubdpt` 与域集槽位值不一致 | 不命中 | "字段比字段"，两侧必须相等 |
| 骨架原样提交（全 null） | 不命中 | 叶子未填值；且 `coverage062008List=null` 时"当前险别"无绑定对象 |
