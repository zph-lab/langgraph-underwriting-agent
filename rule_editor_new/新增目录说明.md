# rule_editor_new

此目录为规则编辑器的完整项目，基于公司仓库 `master` 中现有 `rule-editor`，加入按字段 codeService 限定值域的单选、多选功能。原 `rule-editor` 目录保持不变。

## 本次功能

- 支持属于（单选）、属于（多选）、不属于（单选）、不属于（多选）。
- 下拉支持搜索、回显、确认、取消；多选回填 `[项1,项2]`，保留相邻条件。
- 编辑标注与生成校验共用字典映射，生成真实编码；保留已有规则语法。
- 模型、方法注册表和 SQLite 沿用公司原目录；未混入本地未提交的模型及数据库变更。

## 部署

在本目录执行原有启动或 Docker 构建命令。无需重建 ETL。

部署前在 `rule_editor/config.yaml` 配置登录账号、密码及需要的 ADP token；仓库中的这些值已清空。转换脚本也不再内置默认登录密码，需要时通过参数提供。不要将实际凭据提交到 Git。

如果同时运行旧版和新版，先调整新版 Compose 的容器名、镜像名和宿主机端口，避免与旧版冲突。不要直接假定现有端口空闲。
